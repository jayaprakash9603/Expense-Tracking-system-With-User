# Dashboard components

| Folder | Contents |
|--------|----------|
| [`header/`](header/) | Top bar (`DashboardHeader`) |
| [`quick-access/`](quick-access/) | Shortcut tiles (`QuickAccess`) |
| [`sections/`](sections/) | Dashboard content blocks (spending, categories, budgets, recent activity, cards) |
| [`charts/`](charts/) | Recharts-based widgets shared with analytics (`MonthlyComparisonChart`, trend/breakdown/cashflow, `SpendingChartTooltip`) |
| [`modals/`](modals/) | Feature-specific dialogs (`DashboardCustomizationModal`) |

Import using the `@/features/dashboard/components/<folder>/<FileName>` path pattern.
