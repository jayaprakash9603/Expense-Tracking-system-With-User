# Accessibility Checklist (Phase 6)

## Keyboard and Focus

- [ ] All primary actions reachable via keyboard.
- [ ] Focus indicator visible on interactive controls.
- [ ] Dialogs trap focus and restore focus on close.

## Semantics

- [ ] Inputs include labels and helper/error text associations.
- [ ] Buttons and icons include accessible names.
- [ ] Tables define header scopes.

## Contrast

- [ ] Text contrast meets WCAG AA in light mode.
- [ ] Text contrast meets WCAG AA in dark mode.

## Notifications

- [ ] Floating notifications are dismissible and non-blocking.
- [ ] Toast content is concise and screen-reader friendly.
